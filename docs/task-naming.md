

# Соглашение по именованию задач

Формат:

HBS-<номер> <действие> <объект>

Примеры:

HBS-1 Создать структуру базы данных
HBS-2 Реализовать регистрацию пользователей
HBS-3 Реализовать поиск отелей
HBS-4 Реализовать бронирование номера
HBS-5 Реализовать панель администратора
HBS-6 Реализовать отзывы

Правила:

- Каждая задача должна иметь уникальный последовательный номер.
- Префикс `HBS` обязателен.
- Название должно описывать конкретный результат.
- Избегать слишком общих названий (например, «Работа над проектом»).
- Задачи должны соответствовать GitHub Issues (одна задача — один issue).
