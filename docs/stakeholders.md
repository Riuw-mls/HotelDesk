

# Заинтересованные стороны

| Заинтересованная сторона | Роль                    | Интерес | Влияние |
| ------------------------ | ----------------------- | ------- | ------- |
| Администратор отеля      | Системный администратор | Высокий | Высокое |
| Гость                    | Конечный пользователь   | Высокий | Среднее |
| Зарегистрированный пользователь | Клиент           | Высокий | Среднее |
| Команда студентов        | Команда разработки      | Высокий | Высокое |
| Преподаватель курса      | Академический руководитель | Средний | Высокое |

## Описания

- Администратор отеля: управляет отелями, номерами и бронированиями в системе; заинтересован в корректной доступности и удобстве управления.
- Гость: незарегистрированный посетитель, который ищет отели и просматривает информацию; заинтересован в простоте поиска.
- Зарегистрированный пользователь: аутентифицированный клиент, создаёт и управляет бронированиями; заинтересован в надёжности процессов бронирования.
- Команда студентов: двухчленная команда разработчиков, отвечающая за реализацию проекта.
- Преподаватель курса: академический руководитель, оценивающий результаты и прогресс.
