

# Требования

## Функциональные требования

FR-01 — Система должна позволять гостям искать отели.

FR-02 — Система должна позволять пользователям фильтровать отели.

FR-03 — Система должна отображать информацию об отеле.

FR-04 — Система должна отображать доступные номера.

FR-05 — Система должна позволять зарегистрированным пользователям создавать бронирования.

FR-06 — Система должна позволять пользователям просматривать свои бронирования.

FR-07 — Система должна позволять пользователям изменять бронирования.

FR-08 — Система должна позволять пользователям отменять бронирования.

FR-09 — Система должна позволять пользователям оставлять отзывы.

FR-10 — Администратор должен иметь возможность управлять отелями и номерами.

## Нефункциональные требования

NFR-01 — Интерфейс должен быть понятным и удобным.

NFR-02 — Данные аутентификации пользователей должны быть защищены.

NFR-03 — Система должна предотвращать двойное бронирование (design-level и тестирование).

NFR-04 — Система должна обеспечивать приемлемое время отклика для обычных операций пользователя.

NFR-05 — Система должна быть сопровождаемой и документированной.
