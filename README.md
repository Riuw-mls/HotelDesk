
# Hotel Booking System

## Описание проекта

Hotel Booking System — веб-приложение для поиска отелей, просмотра информации о номерах и создания и управления бронированиями.

## Проблема

* Информация об отелях и номерах может храниться разрозненно или несогласованно.
* Бронирования иногда обрабатываются вручную (телефон, мессенджеры).
* Ручная проверка доступности может приводить к ошибкам.
* Существует риск двойного бронирования.
* Пользователю неудобно отслеживать свои бронирования.

## Цель проекта

Создать веб-систему, позволяющую пользователям искать отели, просматривать доступные номера и управлять бронированиями.

## Основные функции

* поиск отелей
* фильтрация
* информация об отеле
* выбор номера
* проверка доступности номеров
* создание бронирования
* просмотр бронирований
* изменение бронирования
* отмена бронирования
* отзывы
* администрирование отелей и номеров

## Вне области проекта

Следующие пункты явно не включены в начальную версию:

* онлайн-оплата
* банковская интеграция
* интеграция с Booking.com / Airbnb
* мобильное приложение
* программы лояльности
